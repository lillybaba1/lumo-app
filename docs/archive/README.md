# Archived Documentation

This directory contains archived documentation that is no longer actively maintained but kept for historical reference.

## Directory Structure

### `/fixes`
Contains troubleshooting and bug fix documentation from the development process. These documents were created to solve specific issues during development and are kept for reference in case similar issues arise.

**Files:**
- `AI_NOT_WORKING_FIX.md` - AI chatbot troubleshooting
- `BUGFIX_ADD_PRODUCT.md` - Product addition bug fixes
- `EMAIL_VERIFICATION_FIX.md` - Email verification issues
- `FIX_VERCEL_BUILD.md` - Vercel build troubleshooting
- `QUICK_FIX_IMAGES.md` - Image upload quick fixes
- `ROUTE_COMPILATION_FIX.md` - Route compilation issues
- `SIGNUP_VERIFICATION_FIX.md` - Signup verification fixes
- `VERCEL_BUILD_FIX.md` - Additional Vercel build fixes

### `/firebase`
Contains Firebase-related documentation from before the migration to Supabase. Kept for reference purposes.

**Files:**
- `FIREBASE_SETUP.md` - Original Firebase setup instructions
- `FIREBASE_IMAGE_FIX.md` - Firebase image storage troubleshooting
- `FIREBASE_IMAGE_COMPLETE_FIX.md` - Complete Firebase image migration guide

## Note

These documents represent the evolution of the Lumo App project. While they may contain outdated information, they provide valuable context about challenges encountered and solutions implemented during development.

For current documentation, please refer to the main project README and active documentation files in the root directory.
